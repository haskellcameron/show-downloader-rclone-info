A personal utility for transferring and verifying files in the account owner's Google Drive using rclone.

What this application does

The utility runs on the operator's own computer or server. It helps organize prepared files into the operator's chosen Drive folders, transfer missing files, and verify that uploaded content matches the local source.

  • Reads account, storage-capacity, file and folder information needed for a transfer.
  • Creates and manages files or folders according to the account owner's instructions.
  • Checks file names, sizes and content hashes to detect incomplete or duplicate transfers.

Google authorization

Google Drive access is granted separately through Google's authorization screen. The application requests the Drive scope, which can allow access to all files in the authorized account's Drive, excluding the Application Data folder. Its operational workflow is restricted to the folders chosen by the owner.

This is a personal-use application, not a public signup service. Google access is not granted by visiting this website.

What this website does not contain

This static site contains application information and the privacy policy only. It does not host audio, list private Drive files, collect Google credentials or tokens, or provide access to the operator's Drive.

For support or privacy questions, use the developer contact shown on the application's Google authorization screen. Do not send passwords, authorization codes, tokens or private files.
